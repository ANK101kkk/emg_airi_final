# AIRI — декодирование движений кисти

Финальная модель обучена на 80 размеченных записях AIRI одного участника. Веса ансамбля фиксированы. Спектральная TDS–LSTM даёт 37,5% прогноза, TDS–LSTM с фильтром состояний движений даёт 37,5%, ритмическая модель — 25%. Коэффициент причинной экстраполяции между кадрами равен 1,6. Модель выдаёт 20 углов в радианах из 6 синхронных каналов ЭМГ с частотой 500 Гц.

## Файл для соревнования

Для получения phase2_submission.csv распакуйте официальный phase2_public.zip в папку data. Запускайте команды из корня репозитория. Проверено с Python 3.12 на CPU.

```bash
python -m pip install -r requirements.txt
python predict.py --input data/test --template data/phase2_sample_submission.csv --output phase2_submission.csv
```

Для одного файла ЭМГ используйте `python predict.py --input data/test/rec_0e6eb624b58117aa.npy --output angles.npy`. Результат содержит только оцениваемые отсчёты. Индекс 0 в выходном массиве соответствует индексу 1000 в исходной записи.

## Проверка качества

Каждую из 80 записей оценили один раз с исключением всего её дня из обучения. Границы углов для каждого разбиения определены на остальных шести днях. Первые 1000 отсчётов каждой записи служили контекстом. Взвешенная MAE по конкурсной формуле равна 0,116304 рад, обычная MAE — 0,107657 рад. Средний R² по 20 углам равен 0,80058. В 81,24% случаев ошибка не превысила 10°. Семь открытых дней использовались также для сравнения вариантов архитектуры. Оценка относится к новым дням того же человека. Закрытый результат определяют организаторы.

Файл validation/by_day.csv содержит разбивку конкурса по дням. Строки с пометкой fixed соответствуют настройкам финального сабмита. validation/phase2_check.json фиксирует полную сверку 624032 строк шаблона и 12480640 значений после повторного запуска модели. Зависимость от будущего проверена на реальной записи изменением сигнала после выбранного момента.

Для пересчёта метрик по сохранённым прогнозам отложенных дней укажите путь к данным AIRI с подпапкой train. Команда выполняется из папки этого README.

```bash
python validation/verify_oof.py --data data --model-config model_config.json --out replay
```

## Обучение на AIRI

Распакуйте phase1_public.zip в папку data, чтобы файл метаданных находился по пути data/train/metadata.csv. Для повторного обучения всех трёх ветвей на 80 записях выполните следующую команду. Для проверки отдельного дня доступен аргумент --exclude-day DAY_ID.

```bash
python train.py --data data --work runs/cache --out runs/retrained
```

При повторном обучении на тех же данных все четыре файла весов совпали побайтно. Результаты сверки сохранены в validation/retraining_check.json.
